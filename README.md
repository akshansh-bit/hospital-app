🏥 Hospital Management System

A full-stack Hospital Management System built for 
4th Semester DBMS Project.

Tech Stack:
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MySQL (XAMPP)
- AI: Groq API (Llama 3)

Features:
- 👤 Patient Management
- 📅 Appointment Scheduling
- 🩺 Doctor Management
- 📋 Medical Records
- 💳 Billing & Payments
- 🤖 AI Health Assistant
- 📊 Dashboard with Charts

Database Concepts Covered:
- Normalization (1NF, 2NF, 3NF)
- Triggers, Views, Indexes
- Foreign Keys & Constraints

How to Run:
1. Start XAMPP (Apache + MySQL)
2. Import `database/hospital_hms.sql`
3. Run `cd backend && node server.js`
4. Open `frontend/dashboard.html`
